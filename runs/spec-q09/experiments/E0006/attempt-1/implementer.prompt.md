## The issue

### Hash join prefetch distance tuning (16 -> 32) plus prefetch on the probe-retry path

**Hypothesis.** E0004 (software-pipelined prefetch at distance 16, 4MB gate) gave q09 -10..-15%, but the distance was never tuned. The profile still shows the o_orderkey = l_orderkey HASH_JOIN at 1.31s, the largest operator: 15M probe rows against a 3.27M-row build with a 64MB entry table, about 80% misses, so each probe is a DRAM miss. One loop iteration in ProbeForPointersInternal (join_hashtable.cpp:215) costs only a few ns on a miss (empty slot or salt mismatch, then break), so 16 iterations ahead (~50ns) is shorter than DRAM latency (~80-100ns plus TLB miss on a 64MB table). Many prefetches therefore arrive late. A distance of 32 should cover the latency and stay within the line-fill-buffer budget, because the loop issues one prefetch per iteration. The same applies to the build insert loop (InsertHashesLoop, line ~694), which writes into the same 64MB table.

**Plan.** In src/execution/join_hashtable.cpp: change `HT_PREFETCH_DISTANCE` (line 200) from 16 to 32. That constant is used by both ProbeForPointersInternal (line 216) and InsertHashesLoop (line 694). Benchmark q09 at 16, 32 and 48, comparing back to back against the current best, and keep the best. If the time allows, try separate distances for probe and build. Leave the ShouldPrefetch gate (4MB) and everything else alone. Prefetch is only a hint, so results cannot change.

**Target files.** src/execution/join_hashtable.cpp

**Expected gain.** q09: 3-8% (the orders join probe and build, ~1.3s of operator time out of 0.78s total wall with 8 threads).

**Generality.** Any hash join whose entry table is over 4MB (large builds, high-miss probes), e.g. fact-to-fact and fact-to-large-dimension joins in TPC-H/TPC-DS. Small joins are unaffected because of the gate. When a prefetch is wasted (count < distance), only the tail of the vector skips prefetching, so there is little downside.

**Risk.** Low: one constant, no logic change. The main risk is the gain staying within noise.
